Dealing with surds - "isolate and square" them away
But it gets trickier when there's more than one...

Puzzle: Find \(x\) for which

\( \sqrt{(3x+1)}-\sqrt{(x+1)}=2 \)

Solution 1: CLICK TO REVEAL

  1. We need to get rid of those square root signs!
    First, rearrange to get the most complex looking square root on its own...

    2. \( \sqrt{(3x+1)}=2+\sqrt{(x+1)} \)

  2. Now, square both sides...

    3. \( (3x+1) = 4 + 4\sqrt{(x+1)} + (x+1) \)

  3. We still have a term with a square root, from the cross-terms when we squared the RHS.
    Now, rearrange to get that remaining square root on its own...

    4. \begin{align} 2x-4 &= 4\sqrt{(x+1)} \\ x-2 &= 2\sqrt{(x+1)} \geq 0 \end{align}

  4. Note that since \( \sqrt{ } \) is by definition non-negative, \( x-2 \geq 0 \) and so \( x \geq 2 \).
  5. Now square both sides again...

    6. \begin{align} x^2 - 4x + 4 &= 4(x+1) \\ &= 4x + 4 \\ x^2 - 8x &= 0 \\ x(x - 8) &= 0 \\ x &= 0,8 \end{align}

  6. We noted earlier that \( x \geq 2 \) so we rule out \( x=0 \).
    We verify that substituing \( x=8 \) into the original equation gives \( \sqrt{ 25 } - \sqrt{ 9 } = 5 - 3 = 2 \).
    Hence \( x=8 \) is the only solution.

Not here, how important it is to remember about \( \sqrt{ } \) always being negative. More generally, we should realise that whenever we square both sides of an equation, that's a step where the implication goes forward but not backwards. In other words, while each equation we write down from that point on has to be true for any solution, it might also be true for some non-solution/s as well, as with \( x=0 \) in this case. In fact, substituing \( x=0 \) into the original equation would give \( 1 - 1 = 2 \) which is clearly false.
The situation that catches you out is where boths sides of the equation you're squaring have the same absolute value (and hence equal squares) but opposite sign. To cover for this possibility, you basically need to make sure that you add a condition that ensures both sides having the same sign.
At the step where we squared both sides (the second time), we knew the RHS was \( \geq 0 \) by definition of the \( \sqrt{ } \) operator, so we added the requirement \( x \geq 2 \) that would also ensure the LHS \( \geq 0 \).
As an exercise, you chould check the other step involving squaring both sides of the equation. Was there any restriction imposed by needing both sides to be the same sign before that squaring?

How would it have looked if we'd done squaring as our first step?
We still get down to one surd, in the cross-term of the LHS:

\( (3x+1) - 2\sqrt{(3x+1)(x+1)} + {(x+1)} = 4 \)

Rearranging...

\begin{align} 4x - 2 &= 2\sqrt{ ( 3x^2 + 4x + 1) } \\ 2x - 1 &= \sqrt{ ( 3x^2 + 4x + 1) } \geq 0 \end{align}

Note that since \( \sqrt{ } \) is by definition non-negative, we require \( 2x-1 \geq 0 \).

Now square both sides again...

\begin{align} 4x^2 - 4x + 1 &= 3x^2 + 4x + 1 \\ x^2 - 8x &= 0 \\ x(x - 8) &= 0 \\ x &= 0,8 \end{align}

Since we noted earlier that \( 2x-1 \geq 0 \), the only solution in \( x=8 \).
